# Local Codex Gemma Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run folder-local Codex 0.139.0 against a quantized TrevorJS Gemma 4 server, with only Gemma visible in the local model catalog.

**Architecture:** Use llama.cpp as the local OpenAI-compatible inference server for the GGUF quant. Use a project-local `CODEX_HOME` and project-local npm install so global Codex remains unchanged. Generate config, catalog, launch scripts, and verification through a small Python setup helper covered by unit tests.

**Tech Stack:** Python 3.14, npm local package install, `@openai/codex@0.139.0`, llama.cpp Windows binary, Hugging Face GGUF, local TOML/JSON config.
